# Petelib

A collection of Rust libraries and macros for web development and utility functions.

## Components

### thruster-auth
Authentication-related functionality for the Thruster web framework.

### thruster-macros
Macro definitions and utilities for the Thruster web framework.

### usual-macros
General-purpose utility macros for Rust development.

## Getting Started

This repository contains multiple Rust crates. Each component can be used independently or together depending on your needs.

To use any of these components in your Rust project, add them as dependencies in your `Cargo.toml`.
